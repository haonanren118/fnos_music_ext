fnmusic-ext 飞牛音乐扩展

零侵入接管飞牛官方音乐，聚合网易云音乐 / 洛雪音乐 / 音乐DL 三大音源，自带管理 WebUI，Docker 自托管——让飞牛音乐直接在线搜播、自动补全歌词与高清封面。

它能做什么

三音源聚合搜播

在飞牛音乐搜索框输入歌名，聚合网易云 / 音乐DL（酷我·咪咕等）/ 洛雪三音源，即点即播，自动补歌词与封面。

零侵入接管

接管官方后端通信入口，不改官方程序、nginx 与数据库；一条命令即可还原官方直连。

管理 WebUI

浏览器内完成音源切换、网易扫码登录、洛雪源配置、音质偏好与边听边存，全部热生效。

边听边存

在线听歌后台自动缓存，再次播放本地秒开；可把歌曲与内嵌封面、歌词落库到飞牛共享曲库。

封面深度优化

各端各页面真实封面兜底、图片字节缓存、歌单封面后台预热与缓存破除，告别"波纹默认图"。

Docker 自托管

音源合并为单容器，常驻内存约 100–200MB；离线 fpk 安装即跑，无需联网拉取构建。

快速安装

方式一（推荐）：在 fnOS「应用中心 → 手动安装」选择从 GitHub Releases 下载的 fnmusic-ext-<版本>.fpk。

方式二：命令行克隆安装（适合需要改代码的用户）

# 需要已安装 fnOS 官方「飞牛音乐」与 Docker
sudo apt-get update && sudo apt-get install -y python3 python3-venv git
git clone https://github.com/haonanren118/fnos_music_ext.git fnmusic_ext
cd fnmusic_ext
chmod +x install.sh extend.sh restore.sh
./install.sh
